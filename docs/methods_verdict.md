## ③ 是本轮最重要的一条：它推翻了一条既有结论

Phase 4 原本报的是「R1 共振不劣于强对照」，依据是均值差 +0.604 对 +0.181、
精确 p 0.0028 对 0.0573。我据此写下「**场做到了纯分数做不到的事**」。

换成 AUC 之后我先写了一句「两个不同量级的结果」（1.000 对 0.944），
**然后才去查这个差要不要检验**。查出来的结论是：**配对数据必须配对检验**。
成熟做法是 DeLong 检验或配对置换检验（有文献报告 DeLong 在此类规模上不稳而改用置换）。

于是实现了**精确符号翻转检验**（枚举全部 2¹³ = 8192 种交换）+ Holm–Bonferroni 校正：

```
R1 热核 vs R0b 首名分    AUC 差 +0.056   精确 p = 0.7852   Holm 后 1.0000   不显著
```

**不显著。** 36 个配对里 R1 全对、强对照错 2 对，这个差距在 13 条查询的规模上
与纯属偶然完全相容。所以那句「场做到了纯分数做不到的事」撤掉，换成：

> **两者都能分开，但没有任何证据表明场的那一个更好。**

多重校正也确实起了作用：R1 对 ρ均值（c=0.05）原始 p = 0.0195 看着显著，
Holm 之后 0.0781，不显著。

**而 AUC 还顺手抓出一处不稳定**：ρ均值换成 PPR 质量之后，AUC 随传送参数剧烈跳动
（c=0.05 → 0.528，c=0.15 → 0.917，c=0.5 → 0.944）。一个随无关参数跳动的统计量
不能当判据，而 p 值框架完全没提示这件事。

## ① 为什么没有改进（两个角色都测了）

### 作为构造读数

同判据、同意图族、同锚点，只换读数：

```
L0  场本身           0.812
L1m 均值软           0.771   ← 选择几乎不丢信息
L1s sweep软          0.778   ← 换一种选择，也几乎不丢信息
L2m 均值硬           0.413   ← 换成集合比较，丢掉一半
L2s sweep硬          0.167   ← 换成 sweep 集合，丢掉五分之四
```

两条读数：**损失不在「怎么选」，在「用集合比」**；而且 sweep cut 在这里是错的选法——
它取电导最小的前缀，而电导是**图的**性质，意图一动序变但最小前缀往往不变或乱跳。

### 作为判断统计量

把 sweep 电导做成校准读数（拿图自己的节点当零分布），得到 `1−u`：

```
1−u sweep 校准读数    AUC 0.407   ← 反的
ρ sweep 集合          AUC 0.944   ← 与强对照打平
R1 热核（原版）        AUC 1.000
R0b 首名分（强对照）    AUC 0.944
```

1−u 甚至**低于 0.5**：校准读数越低（种子在图里越不寻常）越可能是负例。
原因是它量的是「这个节点在图里特不特别」，不是「这条查询有没有根据」。

### 但它留下了一条可执行检查

`B-D11`：sweep cut 在 c = 0.05 / 0.15 / 0.35 上必须给出同一个切。
实测三档都是 k=16、电导 0.181818181818。**这是"没有位置参数"这句话的可执行形式**——
如果换个 c 就换个构造，那 c 就是一个没被承认的位置参数。

## ⑤ 谱模式敲除：图不动，混淆从设计上不存在

Phase 4 的删节点损伤实验失败，原因是删节点会把**入口集一起换掉**。
本模块不动图，只把场的某一个模式减掉：

```
36 个种子：效应最大的模式是 Fiedler 模（k=1）的次数 = 16/36 = 0.444
随机底 = 1/35 ≈ 0.029       相对底：15.6 倍
模式 1 的位次中位 = 2
```

预测成立。**而且它没有靠事后固定入口集来打补丁——混淆在设计中不存在。**
如实记下另一面：0.444 不是 1.0，所以 Fiedler 模是主导但**不是唯一**。

## ⑥ 合成图：把 n=1 的轶事抬成 n=10 的证据

Phase 1b 在真实图上量到"最负的曲率落在唯一那条界面桥上"，但 n=1。
合成图把埋点抬起来：

| 图 | 界面桥 | 悬边 | OR 界面均值 | OR 悬边均值 | AUC(界面 vs 悬边) | AUC(界面 vs 核内) |
|---|---|---|---|---|---|---|
| 两团相连(6+6) | 1 | 0 | −0.6667 | — | — | **1.000** |
| 5 团成环(size=4) | 5 | 0 | −0.5000 | — | — | **1.000** |
| 4 团成环+3叶/团 | 4 | 12 | −0.5000 | +0.2222 | **1.000** | **1.000** |
| 6 团成环+2叶/团 | 6 | 12 | −0.6000 | +0.2667 | **1.000** | **1.000** |

**埋进去的界面合计 n = 10，四张图全部完全分开。**

### 树的反面对照（这一格比上面更要紧）

随机树 24 节点 23 条边，**全是桥**，但没有界面。它的 OR：正 13 / 负 9，
均值 +0.0435。而 5 团成环 35 条边里 **30 正 5 负，那 5 条负的正好是 5 条埋进去的界面桥**。

所以：**OR 不是"见桥就给负"**。它给负的是「去掉这条边会分开两个各自含有环的区域」的桥。
这一条把 Phase 1b 的结论从"轶事"变成了"在 n=10 上完全分开、并有反面对照"。

⚠️ 仍然如实记：合成图上的度数 R² 是 0.63–0.95，所以 OR 与度数强相关。
它不妨碍区分，但"OR 不是度数代理"这句话只能在真实图那个 R²=0.4199 的语境里说。

## ⑦ 被自己的测试推翻过一次

第一版把「跨群共识」实现成**第一主成分**，并声称「看方向不看数量 ⇒ 多数派免疫」。
免疫测试当场给出 |cos| = 0.40–0.52 —— **不免疫**。

原因是结构性的：第一主成分是**求和**意义下最优，复制一个视图等于给它加权 100 倍。
而 `§C7.1 ①` 要的是**合取**（"要求同时满足所有群，单群不成立"）。
合取的正确形式化是 max-min：`d* = argmax min_i ⟨f_i, d⟩`。

换成 max-min 之后仍只有 0.948–0.996 —— 那是**求解器**的问题，不是准则的问题
（次梯度法的迭代路径会因重复成员而改变）。**先去重再优化**，免疫由构造保证：

```
复制第 1 个视图 100 遍   均值 0.8670   主成分 0.5162   max-min 1.0000
复制第 2 个视图 100 遍   均值 0.7563   主成分 0.4070   max-min 1.0000
复制第 3 个视图 100 遍   均值 0.7749   主成分 0.3995   max-min 1.0000
复制第 4 个视图 100 遍   均值 0.7231   主成分 0.9695   max-min 1.0000
免疫：均值 False / 主成分 False / **max-min True**
```

噪声扫描给出两者的互补关系：

| 噪声 | 主成分 \|cos\| | max-min \|cos\| |
|---|---|---|
| 0.05 | **0.9968** | 0.9776 |
| 0.10 | **0.9872** | 0.9701 |
| 0.20 | 0.9468 | 0.9616 |
| 0.40 | 0.7399 | **0.9299** |
| 0.80 | 0.0347 | **0.8312** |

低噪声主成分更好，高噪声 max-min 好得多。**两者不是替代关系，是取舍。**

诚实登记：条数规则那一格**在本数据上没有区分力**（四个视图的 top-8 有重叠，
被复制的那个视图的节点本来就是条数胜出者），所以它是个弱对照，不能当证据。

## ⑧ 拉普拉斯不适用，但 OR 有效

第一次直接算 Chung 有向拉普拉斯，得到 λ₁ = −1.585 —— 对称化后的拉普拉斯不该有负特征值。
查过之后前提问题清楚了：

```
强连通分量数 = 36（每个节点自成一份）  →  relations 图是**有向无环图**
Chung 构造的定理前提是强连通
照样算出来看它坏成什么样：λ 范围 −2.383482 .. +4.053072，**7 个负特征值**
```

**这不是意外，是设计**：`R3` 禁止成环，`by-situation.md:298` 也明说
「反向关系写在正文里，不写进 relations（否则构成环，被 R3 判错）」。

所以那个对称化对象**不是拉普拉斯**，它的谱不能读成连通性谱。换成 DAG 上对的工具：

```
拓扑层级（到该点的最长路径）   范围 0 .. 7
可达数（向下能到达几个节点）   范围 0 .. 17
```

⚠️ 可达数是**结构量**（完全由图决定），不是热度量，所以不违反 `§C7.1 ①`。

**而有向 OR 不需要强连通，照样有定义**：

```
有向 vs 无向 OR 的 R² = 0.0657     → 方向加了很多（近乎不相关）
最负的边：无向 con-0001—con-0002（−0.5357）
          有向 judge-0006—judge-0009（−0.8000）    不是同一条
```

**坏掉的只有拉普拉斯那一个工具，不是方向这条路。**

## ⑨ 三个 0 的含义完全不同

| 攻击 | 需要什么数据 | 本数据 | 计数 |
|---|---|---|---|
| rebut | 同一对端点上比较**关系种类** | ❌ `relations` 是 `list[str]` | 0 |
| undermine | 同一节点上比较**两个视图的状态** | ⚠️ 有状态，只有一个视图 | 0 |
| undercut | 一个可被指着的**规则对象** | ❌ 没有任何规则对象 | 0 |

**三条都是 0，但 rebut 与 undercut 是结构上表达不了，undermine 是缺第二个视图。**
把它们都记成「无分歧」正是要防的那种混淆。

把"需要什么"钉成可执行的：构造两个视图逐个触发，`rebut 1 / undermine 1 / undercut 1`，
其中 undercut **必须先 `reify`**（把边具体化成有 `rule_id` 的规则对象）才有靶子。

⚠️ `reify` 是演示，不是推荐立刻上：它把图从「节点 + 边」扩成「节点 + 边 + 规则」，
规模与 Phase 7 的多来源同量级，必须走一次结构变更流程。

## ⑩ 抓到的那一个真缺陷

首次在 24 张随机图上跑，`exp(−tL) 保质量` 只有 **12/24** 通过。量出来：

```
最大绝对偏差 = 4.071e-07        当时容差 = 1e-9
L·1 的最大绝对值 = 0.000e+00    （精确）
Jacobi 的正交完备性偏差 max|UUᵀ−I| = 1.776e-15
```

**不变量本身没被违反，是我按超过方法精度的精度在断言**——特征分解在 n=13 上
的数值精度只有 ~4e-7。处理方式：给它起名 `NUM_TOL`（附实测依据），
并按方法精度断言，同时**把实测偏差报出来**。

其余五条（有效电阻是度量、读数对常数平移不变、PPR 总质量归一、
OR 落在 [−2,1]、sweep cut 确实是前缀最小值）在 24 张随机图上全部 24/24 通过。
OR 实测范围 −0.1000 .. +0.5000。

## 这一轮抓到的五处自己的错

| # | 错 | 怎么被抓到 |
|---|---|---|
| 1 | 先写下「两个不同量级」再去跑检验 | 配对检验把它推翻（p = 0.7852） |
| 2 | 配对检验按**名字表**建索引，而返回值按另一个顺序 | 差值出现 −0.593（符号都不对） |
| 3 | B-D6 挖字符串漏了 f-string 字面量（3.12 起是 FSTRING_MIDDLE） | 自检 B-D6c 种入 `f"... p<0.05 ..."` |
| 4 | 把第一主成分当成「跨群共识」的正确形式化 | 免疫测试给出 |cos| = 0.40–0.52 |
| 5 | 直接用 Chung 有向拉普拉斯，没查前提 | 出现负特征值 −1.585 |

五处的共同点：**拿一个邻近的东西替代本该测的那个东西，或者跳过前提直接算。**
这一轮把它们全部记在案，并且每一处都补了一条检查（③→配对检验、
④→B-D6c、⑦→免疫测试、⑧→`laplacian_applicable`）。

## 待办（本轮新增）

1. **conformal 需要可交换的校准集**。机制已验（名义 0.95/0.90/0.80 →
   实测 0.9595/0.9077/0.8043，样本不足时拒绝给门），但真实数据上
   校准集与测试集同分布做不到。**障碍是样本量，不是方法。**
   与既有待办"正例 50 / 负例 20"是同一件事。
2. **方向语义的上游文档冲突**：上游 `aic-123/Scaffold` 的 `SPEC.md` **自己内部矛盾**
   —— 它的散文规则说「A 出现在 B 的 `relations` 里 ⟹ A 指向 B」，
   它自己的方向表说「论据 → 立场」且写进 `relations` 的是论据，两条推出相反方向。
   （`SPEC.md` **不在 rl-scaffold 里**；`by-situation.md:298` 与方向表一侧一致。）
   本模块采用方向表一侧（= `find_path` 的行走方向），但这是一处需要上游拍板的冲突。
3. **`relations` 是有向无环图**这一点值得写进上游文档：它决定了哪些有向工具可用
   （拉普拉斯不行，DAG 层级/可达可以）。
4. **max-min 求解器是局部的**。只报了它达到的最小投影，没报与全局最优的差距。
